# Player Mechanics

## Gameplay Values

| Value | Range | Use |
|---|---:|---|
| Flashlight battery | 0–100% | Drains while the flashlight or EMF reader is active; the light shuts off at zero. |
| Fear | 0–100% | Rises with darkness, depth, and threats; reaching the limit can end the run. |
| Sanity | 0–100% | Falls in darkness and near Meera; affects heart rate and encounter pressure. |
| Sprint stamina | 0–100% | Drains while sprinting and recovers when sprint is released. |
| Noise | 0–100% | Walking, sprinting, distractions, and breath events influence ghost investigation. |
| Evidence | Collected item count | Unlocks progression gates and contributes to ending conditions. |

Run time is measured for completion statistics. The current game does not implement the documented GPA/social values or a 08:00–24:00 day cycle.

## Controls

### Player 1

| Input | Action |
|---|---|
| `W`, `A`, `S`, `D` | Move relative to camera orientation |
| Mouse | Orbit camera by dragging or using pointer lock |
| `Shift` | Sprint while moving |
| `F` | Toggle flashlight |
| `E` | Interact, inspect, collect, or sit/stand when prompted |
| `Q` | Toggle EMF reader |
| `C` | Consume a sanity pill |
| `G` | Throw a distraction item when available |
| `Escape` | Pause; close inventory/settings or leave character selection when open |
| `Tab` / `I` | Open or close the case-file inventory |
| `Space` | Advance dialogue or use Player 1 minigame action when prompted |

### Co-op Player 2

| Input | Action |
|---|---|
| Arrow keys | Move |
| `Period` / `Slash` | Turn camera right / left |
| `Right Shift` | Interact |
| `Right Control` | Sprint while moving |
| `L` | Toggle flashlight |
| `O` | Toggle EMF reader |
| `P` | Consume a sanity pill |
| `H` | Throw a distraction item when available |
| `Period` | Use the Player 2 minigame action when prompted |

The gamepad uses left-stick movement, right-stick camera look, A to interact, X to toggle the flashlight, and L3 to sprint. A second connected controller operates Player 2 in co-op. Mobile uses the left virtual stick to move, right-side touch dragging to look, and on-screen Interact and Flashlight buttons.
